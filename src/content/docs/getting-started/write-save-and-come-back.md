title: Write, save, and come back
description: Write in the editor, save into the Archive, and open that Archive next time.
---

This is the mechanics of a first session. The everyday tasks start after it.

## Write

Click in the editor and write.

You do not have to type formatting marks for ordinary emphasis. Select the words and use the Format menu, or the Style group on the ribbon. Ctrl+B is bold. Ctrl+I is italic. Ctrl+K sets a link.

## Save

Use Save on the ribbon when you want the open piece written into the Archive. The Archive is the folder you chose. The files are on this computer, and they remain yours if you look at that folder outside Studio.

## Come back

Close Studio when you stop. The Archive stays in the folder.

Next time, open Studio, then open the Archive from the File menu (Ctrl+O). The window title shows the Archive’s name when it is open.

If you change a file in that folder with another program, Studio notices and updates what you have open.

You now have an Archive, a place to write, and a way back. The next pages are the everyday tasks, starting with the first person in the work.
