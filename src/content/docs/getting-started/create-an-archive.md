An Archive is the container Studio saves. It is a folder on your computer. The writing goes there, and so does the material you keep around the writing. You choose the folder. You choose the name. You open that same Archive the next time you sit down.

## Create one

1. Open Studio.
2. On the File menu, create an Archive.
3. Choose a folder you can find again, and give the Archive a name you will recognize. When the Archive is open, the window title shows that name.

The prose in the Archive stays as ordinary files in that folder. You can still see them outside Studio. Studio is what keeps the writing and the surrounding material together.

## Open it again

On the File menu, choose Open, or press Ctrl+O, and select the Archive’s folder.

To change the Archive’s name later, use the File menu while it is open. Renaming is covered again when the Archive has more in it.
