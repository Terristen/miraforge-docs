The closed beta is a Windows build you already received. This page is how to install that build and open Studio. There is no download on this site.

## Windows

1. Find the build you were given. Keep it. If you need to install again, use that same build.
2. Run the installer that came with the build, and follow it through. When it finishes, Miraforge Studio is on this computer.
3. Open Studio the way you open any other program you have installed.

The window is ready when Studio is open. It does not yet have your work in it. The next page is how to create an Archive.

If Studio is already installed, open it and continue.
