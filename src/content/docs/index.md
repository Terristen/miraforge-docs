Miraforge Studio is a desktop authoring environment. You write in it. You also keep the material around the writing — people, places, notes, the shape of the work — in the same Archive.

An Archive is the container. You create it, you save into it, and you open it again. What you type into depends on the kind of work. This handbook does not assume one kind.

This handbook is for writers using Studio. It starts with a first session: install the Windows build you already have, create an Archive, find the window, write, save, and come back. Everyday tasks come next. The first of those is a character, the first record that is not the draft. Later tasks are about shaping the work, revising it, and keeping the Archive in order as it grows.

Deeper material comes after those tasks, when you need it. You do not need it to begin.
