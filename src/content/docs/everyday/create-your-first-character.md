---
title: Create your first character
description: Add a person to Lore, the first record in the Archive that is not the draft.
---

A character is the first record that is not the draft itself. The draft is the writing. A character is a person you need to remember, kept in Lore beside that writing.

## Add a person

1. Show Lore if it is hidden. The View menu does this.
2. Lore is grouped by type, and the types belong to this Archive. If a type for people is already there, it may be named Character. That is this Archive’s name for the type. It is not a list you are required to keep.
3. If you have no type for people yet, define one from the menu on the Lore panel. Name the type for the kind of record it will hold.
4. Add an entry under that type. Use the add control on the type, or Lore on the ribbon once the type is selected.

## Name them

Give the person a name. That name is the title of the record. Write the facts you need right now. You can add more later. You do not have to finish a biography before you go back to the draft.

Renaming the person later keeps the same record. You are not starting over, and you do not have to fix a filename to make the new name stick.
